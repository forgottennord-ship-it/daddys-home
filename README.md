# WCC Alchemy - A Witchcraft Language Translator

A learning compiler project that translates a custom Witchcraft language to C.

## Current Features
- Lexer with tokenization of variables, functions, arithmetic operators
- Translator handling variable declarations and expressions
- Complete build automation with Makefile
- Example: Arithmetic calculator and Fibonacci sequence generator (in progress)
